Two owners, two apps, one relay

Alice and Bob each run their own app with only their own keys. The operating system stops each app reading the other’s files: a sandbox policy locally, a separate Unix user per app when hosted. This page plays the public chains and relays their messages, sealed so that it cannot read them.
