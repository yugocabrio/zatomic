THE BOUNDARY

This is an experimental local prototype on Zebra NU7 regtest and Anvil. Both signer processes run on one machine. Refunds use a separate transparent auxiliary input; the exchange principal remains shielded. Reorgs, censorship or outages beyond the timing bounds can break safety. Public-testnet operation and independent security review are still ahead.
